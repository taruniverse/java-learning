# OOP Concepts Notes

OOP means Object-Oriented Programming. It is a way to write programs using objects.
An object usually has data and behavior.

## Main Pillars

- Class and Object: a class is a blueprint, an object is a real thing created from it.
- Encapsulation: keep data private and provide controlled methods.
- Inheritance: one class gets behavior from another class.
- Polymorphism: same method name can behave differently.
- Abstraction: hide details and show only important behavior.

## Other Important Concepts

- Constructor: special method used when creating an object.
- `this`: refers to the current object.
- `super`: refers to the parent class.
- Association: one object knows or uses another object.
- Aggregation: weak "has-a" relationship.
- Composition: strong "has-a" relationship.
- Overloading: same method name, different parameters.
- Overriding: child class changes parent class behavior.
