# Java Basics Notes

This section covers beginner Java building blocks and common keywords.

## Topics

- Access modifiers: `public`, `private`, `protected`, and default.
- `abstract`: incomplete class or method that child classes complete.
- `interface`: contract that classes implement.
- `static`: belongs to the class, not a single object.
- `final`: cannot be changed, overridden, or extended depending on where it is used.
- Variables and data types.
- Methods.
- Packages and imports.
- `enum`: fixed set of values.
- Exception basics: `try`, `catch`, `finally`, `throw`.

Open any folder and run its `Main.java`.
